## 📌 Project Overview

The **Coffee House Sales & Budget Analysis** project is an interactive Power BI dashboard designed to analyze sales performance and compare actual sales with budget targets.

The dashboard provides a clear overview of budget, sales amount, and budget differences, along with monthly performance analysis.

## 🎯 Project Objectives

- Analyze coffee house sales performance.
- Compare actual sales with budget targets.
- Monitor monthly sales and budget trends.
- Identify differences between budget and actual sales.
- Provide insights through interactive visualizations.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Budget
- Total Sales Amount
- Budget Difference

### 2. Monthly Performance Analysis
- Month-wise Budget
- Month-wise Sales Amount
- Budget vs Actual Sales Comparison
- Monthly Budget Difference

### 3. Interactive Filters
- Year Slicer
- Month Slicer
- Dynamic filtering for performance analysis
